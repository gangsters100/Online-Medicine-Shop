# Medicine Shop Project

A long-term full-stack web project for a Medicine Shop.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript (Current Phase)
- **Backend**: Spring Boot (Planned for 6 months from project start)

## Folder Structure
- `frontend/`: Frontend static assets (HTML/CSS/JS).
- `backend/`: Future Spring Boot project.
- `docs/`: Project documentation and Figma links.

## Current Phase: Frontend Development (Mock Data)
- Implementing UI based on Figma: https://www.figma.com/make/qIJYto4tHhBJ0GUP8HCqyQ/Enhance-Online-Medicine-Shop-UI?t=FN2p6E8MFT3czpdl-1
- Using mock data in `frontend/js/data.js` to simulate API endpoints.
