# Design System

This file serves as the source of truth for the project's CSS styling based on the Figma design.

## CSS Variables (`:root`)

Defined in `frontend/css/style.css`:

```css
:root {
  /* Colors */
  --primary-color: #000000;   /* REPLACE WITH FIGMA */
  --secondary-color: #000000; /* REPLACE WITH FIGMA */
  --background-color: #ffffff;
  --text-main: #333333;
  --text-light: #666666;

  /* Typography */
  --font-family-main: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  --font-size-base: 16px;

  /* Spacing */
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
}
```

## UI Components
- **Buttons:** Border-radius, hover states.
- **Cards:** Box-shadow, padding.
- **Forms:** Input fields, labels.
